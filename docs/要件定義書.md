# アンペア消費可視化アプリ 要件定義書

## 1. 概要

### 1.1 目的

家庭で使用する家電の運転状態とアンペア数を登録し、現在動かしている家電の合計アンペア数を可視化する。契約アンペア数などの上限と比較できるようにし、あとどの程度の家電を同時に使用できるか判断するための目安を提供する。

### 1.2 想定ユーザー

- 同時に使用できる家電の量を把握したい家庭の利用者
- ブレーカーが落ちないよう、家電の組み合わせを確認したい利用者

### 1.3 用語

| 用語 | 説明 |
|---|---|
| 上限アンペア数 | 合計アンペア数の比較基準として利用者が設定する値。初期値は20A。 |
| 運転中アンペア数 | 家電が通常運転しているときのアンペア数。 |
| 起動時アンペア数 | 家電の起動時に一時的に必要となるアンペア数。 |
| 有効な家電 | 現在使用中として集計対象になっている家電。 |

## 2. 対象範囲

### 2.1 初期リリースに含めるもの

- 上限アンペア数の表示・設定
- 家電の登録、編集、削除
- 家電ごとの有効／無効の切り替え
- 有効な家電のアンペア数の合計表示
- 運転中アンペア数と起動時アンペア数の切り替え
- 合計と上限の関係を示すグラフおよび状態表示

### 2.2 初期リリースに含めないもの

- 電力計やスマートプラグとの自動連携
- 家電の自動制御、またはブレーカー遮断の予測保証
- 複数回路・相線ごとの負荷計算
- 電気料金や電力量（kWh）の計算

## 3. 機能要件

### 3.1 上限アンペア数

- 初期値を20Aとする。
- 利用者が任意の正のアンペア数を設定できる。
- 現在の合計アンペア数と上限アンペア数を同じ画面で確認できる。
- 入力値が数値でない、ゼロ以下、または許容範囲を超える場合は保存せず、修正方法を表示する。
- 設定値は次回利用時にも保持する。

### 3.2 家電一覧

- 家電一覧に家電名、運転中アンペア数、起動時アンペア数、有効状態を表示する。
- 家電を追加、編集、削除できる。
- 運転中アンペア数は必須とし、0以上の数値で登録する。
- 起動時アンペア数は任意とし、未登録の場合の扱いを明示する。
- 有効状態は家電ごとに切り替えられる。
- 有効な家電のみ合計に含める。
- 一覧から有効状態とアンペア数を容易に確認・変更できる。

### 3.3 アンペア数の集計

- 通常時は有効な家電の運転中アンペア数を合算する。
- 起動時モードが有効な場合は、有効な家電について起動時アンペア数を合算する。
- 起動時アンペア数が未登録の家電がある場合は、運転中アンペア数を代用する案を初期仕様とする。画面上で代用が分かるようにし、代用しない方式が望ましいかは検討事項とする。
- 家電の有効状態、アンペア数、起動時モード、または家電情報が変更されたら、合計とグラフを速やかに更新する。
- 合計値と上限との差（残りアンペア数）を表示する。上限を超過した場合は超過量を表示する。

### 3.4 起動時アンペア数モード

- 初期状態はOFFとし、運転中アンペア数を使用する。
- 利用者がモードをONにすると、起動時アンペア数を使用した集計に切り替える。
- モードの状態が現在どちらの値の集計に反映されているか、画面上で明確に示す。
- このモードは有効な全家電の値を一括で切り替えるものとする。
- 家電が同時に起動する状況を示すものではなく、起動時の値を一律に合算する概算として扱う。

### 3.5 グラフ・状態表示

- 初期案として、家電別の寄与を示す積み上げ横棒グラフを表示する。
- 上限アンペア数を基準線または目盛りで示し、合計が上限以下か超過しているかを判別できるようにする。
- グラフだけに依存せず、合計値、上限値、残りまたは超過量を数値でも表示する。
- 上限内、上限到達、上限超過を色だけでなくテキストやアイコンでも区別する。
- 有効な家電がない場合は合計0Aとして表示し、空の状態を分かりやすく案内する。
- 上限を超えた場合も家電の設定を自動変更せず、注意状態を表示する。

## 4. 画面要件（案）

### 4.1 アンペア状況画面

1. 上限アンペア数と設定操作
2. 現在の合計アンペア数、残り／超過アンペア数
3. 運転中／起動時の集計切り替え
4. 上限を示す積み上げグラフ
5. 家電一覧と各家電の有効状態切り替え
6. 家電の追加・編集・削除操作

### 4.2 家電の登録・編集項目（案）

- 家電名（必須）
- 運転中アンペア数（必須）
- 起動時アンペア数（任意）
- 使用中（有効／無効）
- 任意項目としてメモ（測定条件、出典など）

## 5. データ要件（案）

### 5.1 家電

| 項目 | 必須 | 説明 |
|---|---|---|
| 識別子 | 必須 | 家電を一意に識別する値。 |
| 家電名 | 必須 | 一覧およびグラフに表示する名称。 |
| 運転中アンペア数 | 必須 | 通常運転時のアンペア数。 |
| 起動時アンペア数 | 任意 | 起動時のアンペア数。 |
| 有効状態 | 必須 | 合計に含めるかどうか。 |
| メモ | 任意 | 測定条件や注意事項。 |

### 5.2 アプリ設定

| 項目 | 初期値 | 説明 |
|---|---:|---|
| 上限アンペア数 | 20A | 利用者が設定する集計上の比較基準。 |
| 起動時モード | OFF | OFFは運転中の値、ONは起動時の値を集計する。 |

## 6. 非機能要件

- 合計値は家電一覧と設定の変更を反映して一貫して表示する。
- アンペア数の単位（A）を入力欄、一覧、合計、グラフで明示する。
- 入力エラーは対象項目の近くに説明付きで表示する。
- 画面幅が狭い端末でも、主要な数値、切り替え、家電操作を利用できる。
- 色覚特性やスクリーンリーダーに配慮し、色以外の表現と適切なラベルを用いる。
- データの保存場所、複数端末での共有、バックアップ方法は実装方式決定時に定義する。

## 7. 受け入れ条件

- 初回利用時に上限が20Aとして表示される。
- 上限を変更して再表示しても設定値が保持される。
- 運転中アンペア数の集計が、登録済みの有効な家電の合計と一致する。
- 家電を無効にすると、その家電の値が合計から除外される。
- 起動時モードをONにすると起動時アンペア数に基づく合計へ切り替わり、OFFに戻すと運転中アンペア数へ戻る。
- 起動時アンペア数が未登録の場合、定められた代替処理が画面で分かる。
- 合計が上限以下の場合は残り、超過の場合は超過量が数値と状態表示の両方で確認できる。
- 積み上げグラフの内訳、合計、上限の関係が数値表示と矛盾しない。
- 不正なアンペア数や上限を登録できず、修正方法が利用者に伝わる。

## 8. 検討すべき項目

以下は初期案であり、実装前または実装時に決定する。

1. **上限値の意味**: 20Aは初期値として提示する。契約アンペア数、特定回路の定格、利用者独自の目標値のどれを表すかを明示する。家庭全体の契約容量と個々の回路容量を同一視しない。
2. **起動時の扱い**: 起動時電流は短時間の値であり、すべての家電が同時に起動するとは限らない。起動時モードの一律合算を保守的な参考値として扱うか、起動時対象を家電ごとに選ぶ方式にするかを検討する。
3. **起動時値の未登録時**: 運転中値で代用する案を採用するか、起動時モードでは未設定として警告・集計除外するかを決める。
4. **測定値の入手方法**: 銘板の消費電力から換算する場合の電圧、力率、起動電流倍率、測定器の値のどれを優先するかを決める。換算値は実測値と異なる場合があることを案内する。
5. **入力精度**: 小数点以下の桁数、丸め方法、上限・家電数の最大値を決める。
6. **家電データの保存と共有**: ブラウザー内保存、サーバー保存、ログイン、複数世帯・複数端末共有の要否を決める。
7. **サンプル家電**: 初回利用時に例を表示するか、空の一覧から登録してもらうかを決める。例を表示する場合は実機の値と誤認しない明示が必要。
8. **グラフの適合性**: 積み上げ横棒を初期案とする。家電数が多い場合のスクロール、ラベル、アクセシビリティ、上限を大幅に超える場合の表示範囲を確認する。
9. **複数回路・同時使用**: 家全体の合計だけでは個別ブレーカーや回路ごとの超過を判断できない。回路別管理を将来対応するか検討する。
10. **注意喚起の表現**: 上限超過時に注意を表示するが、実際の遮断・停電を予測または保証しない旨をどこで案内するか決める。

## 9. 前提・注意事項

- 本アプリの合計値は利用者が登録した値に基づく概算であり、電力会社の契約容量、配線、ブレーカー、電圧変動、力率、実際の同時起動条件を計測するものではない。
- 上限以下の表示であってもブレーカーが落ちないことを保証せず、上限超過の表示が直ちに危険や遮断を意味するものでもない。
- 安全な利用・電気設備の判断には、設備の仕様を確認し、必要に応じて有資格者へ相談する。
