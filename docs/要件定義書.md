# アンペア消費可視化アプリ 要件定義書

## 1. 概要

### 1.1 目的

家庭で使用する家電の運転状態とアンペア数を登録し、現在動かしている家電の合計アンペア数を可視化する。契約アンペア数などの上限と比較できるようにし、あとどの程度の家電を同時に使用できるか判断するための目安を提供する。

### 1.2 想定ユーザー

- 同時に使用できる家電の量を把握したい家庭の利用者
- ブレーカーが落ちないよう、家電の組み合わせを確認したい利用者

### 1.3 用語

| 用語 | 説明 |
|---|---|
| 上限アンペア数 | 合計アンペア数の比較基準として利用者が設定する値。初期値は20A。 |
| 運転中アンペア数 | 家電が通常運転しているときのアンペア数。 |
| 起動時アンペア数 | 家電の起動時に一時的に必要となるアンペア数。 |
| 有効な家電 | 現在使用中として集計対象になっている家電。 |
| 起動中の家電 | 有効な家電のうち、起動時アンペア数で集計するもの。 |

### 1.4 決定済みの方針

- 上限アンペア数は利用者が設定する目安値とし、初期値は20A、設定可能な最大値は60Aとする。
- 起動中かどうかは家電ごとに切り替える。起動中の家電は起動時アンペア数、それ以外の有効な家電は運転中アンペア数で集計する。
- 運転中アンペア数は起動時サージを除く通常運転中の高負荷時を基準とする。
- アンペア数は0.1A単位で入力・表示する。
- 参考値に幅がある場合は通常運転時の上側を採用し、0.1A刻みに切り上げる。
- 初期版では100V家電の家全体合計を扱い、200V家電と回路ごとの集計は対象外とする。
- 家電カタログはリポジトリ内のCSVを読み込む。参考アンペア値は100V基準とし、機種による差があることを表示する。
- CSVのアンペア数は製品ごとの仕様値ではなく、出典を付けない一般的な目安値とする。参考値であることと機種差を明記する。
- 参考値の定期・自動更新は行わず、CSVを変更する際に手動で見直す。
- 起動時アンペア数が不明または不確かな場合はCSVで空欄にし、起動時の集計では運転中アンペア数で代用して、その旨を表示する。
- CSVの各家電に初期有効状態を持たせる。初期カタログの家電は無効とし、利用者が使う家電を有効にする。
- 初期カタログには冷蔵庫、電子レンジ、洗濯機、炊飯器、掃除機、電気ケトル、ドライヤー、アイロン、ヘアアイロン、ノートPC、デスクトップPC、ルーターを含める。
- 同じ種類の家電を複数台使う場合は1台ずつ別の家電として登録する。
- 登録できる家電数は、CSV初期分と利用者の追加分を合わせて最大50台とする。
- 家電一覧や設定は開いている間だけ保持する。リロードするとCSVの初期カタログと初期設定に戻る。

## 2. 対象範囲

### 2.1 初期リリースに含めるもの

- 上限アンペア数の表示・設定
- CSVからの家電カタログ読み込み
- 家電の追加、編集、削除
- 家電ごとの有効／無効の切り替え
- 家電ごとの起動中／通常運転中の切り替え
- 有効な家電のアンペア数の合計表示
- 合計と上限の関係を示すグラフおよび状態表示

### 2.2 初期リリースに含めないもの

- 電力計やスマートプラグとの自動連携
- 家電の自動制御、またはブレーカー遮断の予測保証
- 200V家電の登録・集計
- 複数回路・相線ごとの負荷計算
- 電気料金や電力量（kWh）の計算

## 3. 機能要件

### 3.1 上限アンペア数

- 初期値を20Aとする。
- 利用者が正の0.1A刻みで設定できる。最大値は60Aとする。この上限は比較基準の設定値に適用し、個々の家電のアンペア数には適用しない。
- 現在の合計アンペア数と上限アンペア数を同じ画面で確認できる。
- 入力値が数値でない、有限値でない、0A以下、60A超、または0.1A刻みに合わない場合は保存せず、修正方法を表示する。
- 上限値は0.1A単位で設定できる。
- 0.1A単位に合わない値は保存せず、入力欄にエラーを表示する。
- 設定値は画面を開いている間だけ保持する。初期値は20Aとし、リロード後は初期値に戻る。

### 3.2 家電一覧

- 家電一覧に家電名、運転中アンペア数、起動時アンペア数、有効状態を表示する。
- 家電を追加、編集、削除できる。
- 1レコードを家電1台として扱い、同じ家電名のレコードを複数登録できる。
- 登録数はCSV初期分と利用者の追加分を合わせて最大50台とし、上限に達している場合は追加を拒否して理由を表示する。
- リポジトリ内のCSVを初期カタログとして読み込む。CSVの家電名、アンペア数、初期有効状態を表示に反映する。
- 初期カタログのアンペア数は100V基準の参考値であり、機種差があることを利用者に案内する。
- 初期版は100V家電のみを対象とし、200V家電の登録・集計は行わない。
- 家電の追加・編集画面で、登録対象は100V家電に限ることを案内する。
- 初期カタログには冷蔵庫、電子レンジ、洗濯機、炊飯器、掃除機、電気ケトル、ドライヤー、アイロン、ヘアアイロン、ノートPC、デスクトップPC、ルーターを含める。
- CSVには家電名、運転中アンペア数、起動時アンペア数（任意）、初期有効状態、参考値であることを示す注記を含める。製品ごとの出典は持たせない。
- 運転中アンペア数は必須とし、0以上0.1A単位の数値で登録する。
- 起動時アンペア数は参考値を設定できる場合だけCSVに記載する。不明または不確かな場合は空欄とし、登録されていない場合は運転中値で代用する旨を明示する。
- 0.1A単位に合わない値は保存せず、入力欄にエラーを表示する。
- 有効状態は家電ごとに切り替えられる。
- 有効な家電のみ合計に含める。
- 起動中状態は家電ごとに切り替えられる。一覧から有効状態、起動中状態、アンペア数を確認・変更できる。
- 家電カタログや利用者による変更は画面を開いている間だけ保持し、リロードするとCSVの内容と初期状態を再読み込みする。

### 3.3 アンペア数の集計

- 有効な家電のうち、起動中状態がOFFのものは運転中アンペア数を合算する。
- 有効な家電のうち、起動中状態がONのものは起動時アンペア数を合算する。
- 起動時アンペア数が未登録の場合は運転中アンペア数を代用し、当該家電に起動時値が未登録であることを表示する。
- 家電の有効状態、起動中状態、アンペア数、または家電情報が変更されたら、合計とグラフを速やかに更新する。
- 合計値と上限との差（残りアンペア数）を表示する。上限を超過した場合は超過量を表示する。

### 3.4 起動中状態

- 起動中状態は家電ごとに切り替え、初期値はOFFとする。
- 起動中状態がOFFの場合は運転中アンペア数、ONの場合は起動時アンペア数を合計に反映する。
- 起動中状態の切り替えは、その家電が使用中であることを意味しない。有効状態とは別に管理する。
- 起動時アンペア数が未登録の場合は運転中アンペア数で代用し、一覧で未登録であることを明示する。

### 3.5 グラフ・状態表示

- 家電別の寄与を区分で示す積み上げ横棒グラフを1本表示する。
- 現在の集計値が大きい上位10家電を個別区分で表示し、残りの家電は合算した「その他」区分にする。家電が10件以下の場合は、すべて個別区分で表示する。
- 上位10家電は現在選択中の集計値の降順で選ぶ。「その他」にまとめた家電も合計値には含める。
- 凡例には表示中の区分の家電名とアンペア数を表示し、「その他」には合算値を表示する。
- 横棒上に上限アンペア数のマーカーを表示する。合計が上限を超える場合は、合計全体が収まるよう目盛りを自動調整し、全区分と上限との位置関係を判別できるようにする。
- グラフだけに依存せず、合計値、上限値、残りまたは超過量を数値でも表示する。
- グラフには読み上げ用の説明を付け、合計数値と家電一覧をテキストによる代替情報として利用できるようにする。専用の重複データ表は追加しない。
- 上限内、上限到達、上限超過を色だけでなくテキストやアイコンでも区別する。
- 上限超過時は画面内バナーで超過量を表示する。モーダルなどの操作を妨げる表示は使わない。
- 100V家電の入力値に基づく家全体の目安であり、200V家電や個別回路の容量を扱わず、実際のブレーカー遮断も保証しない旨の注意書きを常時表示する。
- 有効な家電がない場合は合計0Aとして表示し、空の状態を分かりやすく案内する。
- 上限を超えた場合も家電の設定を自動変更せず、注意状態を表示する。

## 4. 画面要件（案）

### 4.1 アンペア状況画面

1. 上限アンペア数と設定操作
2. 現在の合計アンペア数、残り／超過アンペア数
3. 家電ごとの有効／無効および起動中／通常運転中の切り替え
4. 家電別の寄与と上限マーカーを示す積み上げ横棒グラフ
5. 家電一覧と各家電の有効状態切り替え
6. 家電の追加・編集・削除操作

### 4.2 家電の登録・編集項目（案）

- 家電名（必須）
- 運転中アンペア数（必須）
- 起動時アンペア数（任意）
- 使用中（有効／無効）
- 起動中（有効な家電ごとに切り替え）
- 任意項目としてメモ（測定条件、出典など）

## 5. データ要件（案）

### 5.1 家電

| 項目 | 必須 | 説明 |
|---|---|---|
| 識別子 | 必須 | 家電を一意に識別する値。 |
| 家電名 | 必須 | 一覧およびグラフに表示する名称。 |
| 運転中アンペア数 | 必須 | 通常運転時のアンペア数。0.1A単位。 |
| 起動時アンペア数 | 任意 | 起動時のアンペア数。0.1A単位。 |
| 初期有効状態 | 必須 | CSVから読み込んだとき合計に含めるかどうか。初期カタログは無効。 |
| 有効状態 | 必須 | 現在の画面で合計に含めるかどうか。 |
| 起動中状態 | 必須 | 現在の画面で起動時アンペア数を使うかどうか。初期値はOFF。 |
| メモ | 任意 | 測定条件や注意事項。 |

### 5.2 アプリ設定

| 項目 | 初期値 | 説明 |
|---|---:|---|
| 上限アンペア数 | 20A | 利用者が設定する集計上の比較基準。 |
| 保存期間 | 画面を開いている間 | リロードすると上限は20A、家電はCSVの初期状態に戻る。 |

### 5.3 初期家電カタログの参考値（暫定）

以下をCSVの初期参考値とする。運転中値は起動時サージを除く通常運転中の高負荷時を基準にし、参考値に幅がある場合は上側を0.1A刻みに切り上げる。値は100V環境の一般的な目安であり、製品の定格値や実測値を示すものではない。初期有効状態はすべてOFFとする。参考値はCSVを変更する際に手動で見直し、定期・自動更新は行わない。

| 家電名 | 運転中アンペア数 | 起動時アンペア数 | 備考 |
|---|---:|---:|---|
| 冷蔵庫 | 2.5A | 空欄 | 450L級を想定した目安。容量・機種で差がある。 |
| 電子レンジ | 15.0A | 空欄 | 大型機種の加熱時を想定した目安。 |
| 洗濯機 | 5.0A | 空欄 | 洗濯運転時の高負荷目安。乾燥機能使用時は大きく異なる。 |
| 炊飯器 | 13.0A | 空欄 | 5.5合IH炊飯器の炊飯時を想定した目安。 |
| 掃除機 | 10.0A | 空欄 | 強運転時を想定した目安。 |
| 電気ケトル | 13.0A | 空欄 | 1300W級を想定した目安。 |
| ドライヤー | 12.0A | 空欄 | 強運転時を想定した目安。 |
| アイロン | 14.0A | 空欄 | 高出力機種を想定した目安。 |
| ヘアアイロン | 1.5A | 空欄 | 150W級を想定した目安。 |
| ノートPC | 0.7A | 空欄 | 65W級ACアダプターでの高負荷を想定し、0.1A刻みに切り上げた目安。 |
| デスクトップPC | 1.5A | 空欄 | 150W級の一般的な構成を想定した目安。 |
| ルーター | 0.2A | 空欄 | 15W級を想定し、0.1A刻みに切り上げた目安。 |

起動時アンペア数は、家電の種類や容量を特定しないと一律の参考値を決めにくいため、初期カタログでは空欄とする。起動中状態がONの場合も運転中アンペア数で集計し、起動時値未登録の表示を行う。

## 6. 非機能要件

- 合計値は家電一覧と設定の変更を反映して一貫して表示する。
- アンペア数の単位（A）を入力欄、一覧、合計、グラフで明示する。
- 入力エラーは対象項目の近くに説明付きで表示する。
- 画面幅が狭い端末でも、主要な数値、切り替え、家電操作を利用できる。
- 色覚特性やスクリーンリーダーに配慮し、色以外の表現と適切なラベルを用いる。
- 家電一覧と設定は画面を開いている間のみ保持し、リロードで初期状態に戻す。

## 7. 受け入れ条件

- 初回利用時に上限が20Aとして表示される。
- 正の0.1A刻みで最大60Aまでの上限値を設定できる。
- 60.0Aは設定でき、60.0Aを超える値は保存されず、上限が60Aである旨が表示される。
- 上限を変更すると、開いている間は変更後の値が表示に反映される。
- リロードすると、上限は20A、家電はCSVで定義された初期状態に戻る。
- 運転中アンペア数の集計が、登録済みの有効な家電の合計と一致する。
- 家電を無効にすると、その家電の値が合計から除外される。
- 同じ家電名の家電を複数登録でき、それぞれの有効状態・起動中状態が独立して集計される。
- 起動中状態を切り替えると、その家電だけ起動時アンペア数（未登録の場合は運転中の値）が合計に反映される。
- 起動時アンペア数が未登録の場合、運転中値で代用していることが画面で分かる。
- CSVで定義した初期有効状態とアンペア数が読み込まれる。
- CSV初期分を含む家電が50台ある場合、それ以上追加できず、上限に達したことが表示される。
- 合計が上限以下の場合は残り、超過の場合は超過量が数値と状態表示の両方で確認できる。
- 上限超過時に画面内バナーで超過量が表示され、100V基準・回路別集計なし・遮断保証なしの注意書きが常時表示される。
- 積み上げグラフは上位10家電を個別表示し、残りを「その他」にまとめ、全区分の合計が数値表示と一致する。
- グラフの凡例に家電名とアンペア数が表示され、「その他」には合算値が表示される。
- グラフに読み上げ用説明があり、合計数値と家電一覧から同じ情報をテキストで確認できる。
- 積み上げグラフの合計と上限マーカーの関係が数値表示と矛盾しない。
- 不正なアンペア数や上限を登録できず、修正方法が利用者に伝わる。
- 0.1A単位に合わないアンペア数は保存されず、入力欄にエラーが表示される。

## 8. 実装時の確認事項

- 画面幅が狭い場合でも上位10件と「その他」の凡例を確認できるようにする。
- グラフ内の区分を色だけで区別せず、スクリーンリーダーで読み上げ可能な説明と数値情報を提供する。

## 9. 前提・注意事項

- 本アプリの合計値は利用者が登録した値に基づく概算であり、電力会社の契約容量、配線、ブレーカー、電圧変動、力率、実際の同時起動条件を計測するものではない。
- 初期版は100V家電のみを扱い、200V家電と個別回路の電流は集計しない。表示する家全体の合計は、実際の契約容量や各回路の負荷を表すものではない。
- 上限以下の表示であってもブレーカーが落ちないことを保証せず、上限超過の表示が直ちに危険や遮断を意味するものでもない。
- 安全な利用・電気設備の判断には、設備の仕様を確認し、必要に応じて有資格者へ相談する。
